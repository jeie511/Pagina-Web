# Super Smash Bros. Ultimate - Landing Page Project

Este proyecto consiste en una Landing Page dedicada al videojuego **Super Smash Bros. Ultimate** para Nintendo Switch. La web está diseñada para ofrecer una experiencia visual inmersiva que refleja la estética oficial de Nintendo, integrando funcionalidades interactivas y contenido multimedia.

## 1. Instrucciones de Inicio/Ejecución
Para visualizar la página web localmente:
1. Descarga o clona el repositorio en tu equipo.
2. Asegúrate de tener todos los archivos en la misma carpeta raíz (especialmente `index.html`, `videos.html`, `stages.html`, `style.css` y `main.js`).
3. Abre el archivo `index.html` en cualquier navegador web moderno (Chrome, Firefox, Edge, etc.).

## 2. Funcionalidades Principales
1. **Sistema de Navegación Dinámico:** Menús adaptados con estética oficial y navegación fluida entre secciones (Inicio, Luchadores, Escenarios, Música y Vídeos).
2. **Hero Slider Animado:** Carrusel de imágenes en la página de inicio con transiciones automáticas que muestran los momentos clave del juego.
3. **Galería de Vídeos con Destacado:** Sección de vídeos que incluye un reproductor destacado para el tráiler "Everyone is Here!" y una rejilla para presentaciones de luchadores.
4. **Grid de Escenarios Dinámico:** Visualización de los más de 100 escenarios del juego con carga optimizada de imágenes.
5. **Control de Acceso y Cookies:** Modal de política de cookies obligatorio al inicio y scripts de verificación de acceso para secciones protegidas.

## 3. Estructura del Proyecto
* `index.html`: Página principal con el Hero Slider, sección de información, vídeos destacados y acceso al blog.
* `videos.html`: Galería multimedia con el tráiler principal en formato grande y una rejilla de vídeos de personajes (Sora, Kazuya, Sefirot, etc.).
* `stages.html`: Listado completo de escenarios con numeración y miniaturas.
* `style.css`: Archivo de estilos principal que define la paleta de colores (Rojo Nintendo, Negro, Blanco) y la responsividad.
* `main.js`: Lógica para el funcionamiento del slider, modales y otras interacciones.

## 4. Diseño y Estética
El proyecto utiliza la identidad visual de Nintendo:
* **Colores:** Uso predominante del Rojo Nintendo (`#e60012`) en cabeceras y botones, con fondos oscuros para resaltar el contenido.
* **Tipografía:** Integración de 'Roboto Condensed' y 'Roboto' para mantener un estilo moderno y legible.
* **Componentes:** Botones con efectos hover, tarjetas de vídeo con iconos de reproducción y menús con desenfoque de fondo (*backdrop-filter*).

## 5. Responsividad
La web ha sido diseñada para ser responsive, ajustando el número de columnas en las rejillas de vídeos y escenarios según el tamaño de la pantalla, y asegurando que el contenido sea legible tanto en escritorio como en dispositivos móviles.
